## 结论与边界

已交付 Windows 桌面程序、CLI、共享核心、测试资产、构建脚本及说明文档。核心下载—解密—恢复—后处理—播放工作流已实际运行。**本报告不将自动测试数量等同于 30 个综合 P0 用例全部通过；正式发布门槛仍以以下未完成项为准。**

## 性能实测

以下为同一 Windows 设备上的发布构建结果，未在测试时并行编译。完整原始样本保存在 `validation`。

| 指标 | 实测 | 结论 |
|---|---|---|
| 1,000 分片纯解析 | 5 次预热、100 次测量，p95 0.8177 ms | 通过 <200 ms；`parser.json` |
| 进程冷启动 | 5 次：683 / 684 / 656 / 920 / 1,015 ms | 通过 <3 s |
| 下载中界面反馈 | 300 次输入到下一帧，p95 18.6 ms | 通过 <200 ms；为合成输入测量 |
| 工作集峰值 | GUI、核心及全部 WebView 子进程之和 557,846,528 字节，约 532.0 MiB | **未通过 <512 MiB** |
| 下载吞吐 | 3 轮中位耗时：基线 7,457 ms，应用 10,160 ms，比值 73.4% | **未通过 ≥80%** |

网络样例为回环 HTTP 服务端、1,000 片，每片 2,097,140 字节（为 TS 包对齐，比 2 MiB 少 12 字节），默认 8 并发。基线同样落盘并 fsync；应用还执行哈希、原子替换和 FULL 数据库提交。媒体工具故意设置为不可用，以测量完整下载阶段，最终断言 1,000 片全部完成；此测试不验证媒体输出。FFmpeg/ffprobe 工作集单独记录。

`performance.json` / `performance-console.txt` 为轻量 CDP 连接的最新完整 5+3 轮结果。此前 Playwright 连接结果 `performance-playwright.json` 吞吐 84.5%、工作集约 525.2 MiB；更早的结果也予以保留。两种驱动都仅在测试子进程环境开启回环调试端口。轻量连接不注入 Playwright 脚本，但**仍不等于完全无调试的生产测量**。吞吐存在跨轮波动，不能只引用达到 80% 的一轮作为通过依据。

无调试端口的测量尝试因 Windows Computer Use 原生管道无法连接而中止，未取得任务下载数据，不记为通过。没有通过排除 WebView 子进程、降低并发、修改指标或主动换出工作集来规避门槛。回环网络也不能替代规格建议的独立局域网服务端验收。

## 安装、便携及原生桌面验证

安装包 `M3U8 Studio_0.1.0_x64-setup.exe` 在全新隔离的中文/空格路径静默安装成功；测试前检查未覆盖已有安装。随包媒体工具的 SHA-256 与构建清单一致。测试结束卸载返回 0，程序文件已移除。记录见 `validation/installer.json` 和 `installer-console.txt`。

便携目录中的桌面 EXE 与 CLI 均实际运行，且与发布构建二进制一致。CLI 在独立中文目录完成本地 HLS 下载，使用随包 FFmpeg 完整解码输出；记录见 `validation/portable.json` 和 `portable-console.txt`。两种运行方式都将被测程序 PATH 限制为 System32，证明不依赖系统安装的 FFmpeg。测试设备已有 WebView2，**未验证无 WebView2 的全新系统离线安装**。

两种包各执行以下原生流程：实际表单解析并下载、任务事件、分片及尝试详情、暂停/继续/重复开始/取消/删除、缺片先确认后输出、携 Cookie 的 AES HLS 预览与定位、本地 TS 临时转封装及 asset 播放。原生测试无前端运行异常。安装版启动 735 ms、暂停 40 ms、取消 29 ms、预览首帧 1,437 ms；便携版分别为 733 / 44 / 28 / 1,461 ms。这些是单轮冒烟测量，启动性能正式口径见前节的五轮数据。

便携 ZIP 包含桌面端、CLI、运行库、启动脚本、使用/验收文档和许可证；`SHA256.json` 校验包内文件，`BUILD-MANIFEST.json` 记录源码提交及构建来源。`release/release-manifest.json` 记录 ZIP 与安装包的 SHA-256；归档完整性结果在 `release/archive-verification.json`。本地验证产物未签名，远程 CI 尚未运行。

## P1 范围
