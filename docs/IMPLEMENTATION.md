# 实施与验证记录

依据：需求规格说明书 V1.1，用户于 2026-11-03 授权按实施步骤开发。

## 实施决策

- Windows x64 为当前环境的首个实测目标；Linux/macOS 保留代码兼容目标，不将未实测平台标为已通过。
- Rust 核心、Tauri 2 + Vue 3、SQLite、FFmpeg/ffprobe。在线预览采用 hls.js 自定义加载器，经 Rust 网络层取资源，不新增监听端口。
- 一期保留全部 P0 的实现方向，独立 AAC TS 音轨和 WebVTT；fMP4/直播识别并拒绝。命令行同时作为集成验收入口。
- 开发过程中使用本机 FFmpeg；发布材料记录实际构建和许可证，不把开发依赖误认为已完成分发审查。
- 核心接口集中在任务引擎：解析、创建、启动、暂停、取消、更新、删除、订阅事件。界面不直接修改 SQLite 或凭证存储。

## 开发顺序

1. 解析与媒体测试样例。
2. 受控网络、解密、缓存及持久化。
3. 任务状态、并发、暂停和崩溃恢复。
4. 音轨、字幕、输出验证与 CLI 集成验收。
5. 桌面界面和鉴权预览。
6. 打包、性能/安全测试、需求追踪与审查。

完成情况以验收报告为准；本文件不宣称尚未实现的功能已通过。
