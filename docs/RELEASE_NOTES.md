# 0.1.0 本地验收构建

日期：2026-11-03。首个实际验证平台为 Windows 11 x64。该版本提供完整的下载到媒体输出工作流；是否满足正式发布门槛，以 ACCEPTANCE.md 的逐项证据为准。

## 已实现

- Rust 核心、Tauri/Vue 桌面工作台和同引擎命令行。
- 本地/远程点播列表、主列表选流、独立音轨、WebVTT、AES-128 密钥轮换与手动上下文。
- 受控请求头、认证代理、限速、有限重试、范围请求、分片校验恢复。
- 暂停、继续、取消、历史记录、缓存管理、缺片确认与报告。
- MP4/MKV/TS 输出、H.264/H.265/AAC 转码、媒体检查、默认不覆盖及显式覆盖保护。
- 鉴权 HLS 在线预览、本地媒体播放、双语界面、主题、日志及操作系统安全存储。
- Windows NSIS 安装和便携打包流程，随包提供固定构建的 FFmpeg/ffprobe。

## 本轮重要修复

- 输出在验证完成后提交；默认不覆盖已有媒体、字幕或缺片报告。
- 显式覆盖不得替换本地输入或写入任务缓存；失败时回滚本次已替换的文件。
- 缓存拒绝目录联接/符号链接；使用随机临时文件提交，避免写穿现有链接。
- 完整缓存可在源站离线、原访问凭据未记住时重试后处理。
- 手动密钥变更只影响相关上下文的分片；仅 IV 的覆盖也会在重启后要求补充。
- 保存界面设置不会放大正在使用的请求额度；改变并发上限需先释放相关工作。
- 快速 TS 检查所有分片的流结构，并拒绝纯视频/转码等需要重新封装的组合。
- 明显不匹配的独立音轨时长、选定字幕失败不会再产生普通成功结果。
- 分片落盘和事务提交移出异步网络轮询；相邻提交合并事务，成功回执仍在 FULL 提交之后。取消时等待已派发工作退出。
- 播放器按需加载；默认窗口 1200×760，适配笔记本工作区并减少未播放时的图形内存开销。

## 使用边界

当前性能门槛尚未全部满足：最新完整测量的 GUI/核心及 WebView 工作集峰值约 532 MiB，吞吐相对落盘基线为 73.4%（前一轮 84.5%）。解析、冷启动和界面响应达到目标；完整样本和测量差异见 ACCEPTANCE.md。本包用于本地试用验收，不能据此宣称所有 P0 已交付通过。

本版拒绝直播、fMP4、DRM/SAMPLE-AES。便携版要求系统已有 WebView2；安装包包含其离线安装器。包未签名。Linux/macOS 的安装、原生预览及安全存储尚未实际验收。

所有成功输出都会检查结构、时长并进行初段采样解码；受控集成测试进一步进行完整解码。输出媒体和旁置文件逐一提交，应用级错误可回滚，不宣称断电时多个文件具有单一原子事务语义。

公开分发的对应源码和第三方材料门槛见根目录 THIRD_PARTY_NOTICES.md；不能以本地构建或自动测试替代该项审核。
